# 小红书选题方法

这是"选题策划"角色的工作框架。职责：拆解对标爆款、跟踪热点、维护选题库，回答账号"这周发什么"。本 skill 给出可直接套用的拆解框架、选题库模板和判断标准——产出的选题要能直接交给写作环节（见末尾"协作")。

小红书的底层逻辑：**笔记靠搜索和推荐被发现，不靠粉丝。** 一篇笔记能不能火，70% 在选题，20% 在标题封面，10% 在正文。所以选题是第一道关，也是回报最高的一关。

---

## 一、爆款拆解框架

拿到一篇爆款笔记（自己的或对标的），不要只看"它火了"，要拆"它为什么火"。按五个维度过一遍，每个维度回答下面的清单问题。目标是把"运气"翻译成"可复制的动作"。

### 1. 选题角度（最重要）
- 它解决的是用户的什么具体问题？用户会在搜索框打什么字找到它？
- 同一个话题，它选的是大众都讲的角度，还是一个新切口？新在哪？
- 它瞄准的是哪类人群？这群人的痛点有多痛、多普遍？
- 它是常青需求，还是踩中了某个季节/热点？

### 2. 标题钩子
- 第一眼抓住人的是什么？数字、反差、身份标签、还是制造好奇？
- 标题里有没有用户会搜的关键词？（搜索流量靠这个）
- 有没有"利益点"——看完能得到什么，是否说清楚了？
- 字数是否克制（小红书标题约 20 字内露出最佳）？有没有 emoji 点缀？

### 3. 封面
- 封面 3 秒内传递的核心信息是什么？是大字报、实拍、还是对比图？
- 文字够不够大、够不够少？信息密度是否过载？
- 视觉风格和目标人群匹配吗？（精致 vs 接地气）
- 和信息流里其他笔记比，它靠什么跳出来？

### 4. 正文结构
- 开头第一句怎么留住人？（共情 / 抛结论 / 制造悬念）
- 主体是怎么组织的？清单体、步骤体、故事体、还是测评对比？
- 有没有"值得收藏"的信息密度？（收藏是小红书的核心权重）
- 结尾怎么引导互动？提问、求扩列、还是引导评论？

### 5. 评论区运营
- 评论区有没有"神评论"或作者补充的关键信息？（评论区是第二战场）
- 作者有没有用置顶评论补钩子、引导互动？
- 高赞评论反映了用户真正关心什么？（这是下一篇选题的金矿）

> **拆解的产出**：每拆一篇，沉淀 1 句"可复用的成功要素"（如"用'避坑'角度切大众话题，封面用红黑对比大字"），存进选题库的"对标参考"字段。

## 二、选题库方法（人群痛点 × 内容形态 × 热度周期）

选题不靠灵感，靠一张可持续补充的表。用三个维度交叉，就能批量生产候选选题，不会"想一个少一个"。

### 三个维度的取值示例

**维度 1 — 人群痛点**（这群人在焦虑/纠结什么）
- 按人群细分：新手小白 / 进阶用户 / 预算有限 / 时间紧张 / 选择困难……
- 按痛点细分：不知道怎么选、怕被坑、想省钱、想速成、怕做错决定……
- 取值要"具体到能搜"：不是"想理财"，而是"工资到手剩不下钱怎么办"。

**维度 2 — 内容形态**（用什么形式承载）
- 测评：横向对比多个产品/方案，给结论
- 教程：手把手分步骤，可操作
- 避坑：盘点常见错误，反向价值
- 种草：单品/单方案安利，带场景
- 对比：A vs B 二选一，帮用户做决策
- 清单/合集：N 个 xx 一次给全，高收藏
- 故事/经历：真实第一人称，强共情

**维度 3 — 热度周期**（什么时候发最合适）
- 常青：任何时候搜的人都多（如"新手怎么入门"）——选题库的压舱石
- 季节：跟节气/节日/季节走（如年终、618、过年、换季）——提前 1-2 周布局
- 突发热点：平台正在热的话题/事件——24-48 小时内蹭，过期作废

### 选题表字段

维护成一张表（飞书/Notion/Excel 均可），每行一个候选选题：

| 字段 | 说明 |
|------|------|
| 标题方向 | 一句话说清这篇讲什么（不是最终标题，是方向） |
| 切入角度 | 三维定位：人群痛点 + 内容形态 + 热度周期 |
| 对标参考 | 链接 + 那篇爆款的"可复用成功要素" |
| 预期人群 | 这篇想打中谁，他们会搜什么词 |
| 状态 | 待写 / 写作中 / 已发布 / 已归档 |

**补充节奏**：拆一篇对标补几行，蹭一个热点补几行，看一次评论区补几行。表永远不空，"这周发什么"随时有答案。

## 三、选题判断标准

候选选题进表前，过这三关。任意一关不过，降优先级或砍掉。

1. **痛点真实**——用户会主动搜的，才是真选题。如果这个问题没人会去搜索框打字找答案，再"有道理"也是自嗨。判断法：把切入角度想象成搜索词，自己会搜吗？身边人会搜吗？
2. **角度差异**——同一话题已经被讲烂了，必须给新切口。如果你的角度和前排笔记雷同，平台不会再推一篇一样的。差异可以来自：更细的人群、更具体的场景、反向视角（避坑）、或更新的形态。
3. **匹配定位**——不匹配人设/账号定位的热点，果断放弃。蹭一个跟账号无关的热点，即使来了流量也是无效粉，还会稀释账号标签。宁可错过，不要乱接。

## 四、完整示例（黄金珠宝账号）

**场景**：一个小红书黄金珠宝账号，主打"黄金+珠宝选购建议"，目标人群是 25-35 岁想买黄金保值/送礼的女性。问"这周发什么"。

### 第一步：拆一篇对标

对标笔记：《买金子千万别踩这几个坑！我交了 3000 块学费》

- **选题角度**：切"新手买金怕被坑"的痛点，用"避坑"反向角度——大众都在种草，它反着来讲教训，差异明显。瞄准第一次买金、信息不对称的新手。常青需求。
- **标题钩子**：数字"3000 块学费"制造损失共情 + "千万别踩"的警告句式，关键词"买金子""踩坑"都是高搜索词。
- **封面**：红黑大字"买金避坑"，配一张金饰实拍，对比强烈、信息一眼到位。
- **正文结构**：清单体，5 个坑分点讲，每个坑带亲身经历，收藏价值高。
- **评论区**：高赞评论在问"那 XX 牌子靠谱吗"——暴露出"品牌怎么选"是下一个选题金矿。
- **可复用成功要素**：用"避坑+学费"角度切大众种草话题，封面红黑大字，清单体讲亲身教训。

### 第二步：产出 3 个选题

基于拆解（尤其评论区暴露的需求），用三维方法各给一个：

1. **《黄金克价怎么算才不被宰？算给你看》**
   - 切入角度：预算敏感人群痛点 × 教程形态 × 常青
   - 为什么：评论区和搜索都高频问"克价/工费怎么算"，真实痛点；教程形态承接"避坑"之后的"那到底怎么做"。

2. **《周大福 vs 老凤祥 vs 菜百，新手买金选哪家》**
   - 切入角度：选择困难人群痛点 × 对比形态 × 常青
   - 为什么：直接接住对标评论区"XX 牌子靠谱吗"的需求；对比形态帮用户做决策，强收藏。

3. **《过年给妈买金，预算 5000 怎么挑最有面子》**
   - 切入角度：送礼场景人群痛点 × 种草+清单形态 × 季节（年前）
   - 为什么：踩中过年送礼季节窗口，场景具体（给妈/预算 5000），人群和搜索词都很明确。

三个选题覆盖了不同形态和周期，既有常青压舱也有季节蹭热，且都能直接说出"用户会搜什么"。

## 协作

本 skill 属于小红书内容创作 team 的选题环节，是流水线第一棒。选题产出（选题表的一行：标题方向 + 切入角度 + 对标参考 + 预期人群）要完整清晰，方便顺手交给下游：

- **xhs-note-writing（写作）**：拿选题的"标题方向 + 切入角度 + 对标的正文结构要素"去写标题和正文。
- **xhs-visual-method（配图）**：拿"对标封面的可复用要素 + 预期人群视觉偏好"去做封面和配图。
- **xhs-publish-playbook（发布）**：拿"热度周期"判断发布时机（季节/突发热点要卡窗口）。

交付一个选题时，至少把"切入角度"和"对标参考"写实——下游靠这两项才知道怎么承接。
