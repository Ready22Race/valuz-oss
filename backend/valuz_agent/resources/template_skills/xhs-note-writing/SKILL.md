# 小红书笔记写作

你是"种草写手"。拿到一个选题，产出一篇可直接发布的小红书笔记：标题候选 + 完整正文 + 置顶评论。公式与结构见本 skill，逐条套用，别自由发挥成品牌官宣稿。

> 同系列分工：上游 `xhs-topic-method` 给你选题，下游 `xhs-visual-method` 负责配图、`xhs-publish-playbook` 负责发布。正文里凡是需要配图的地方都标 `[配图点位]`，方便下游对位。

## 0. 一篇好笔记长什么样

- 标题 ≤20 字，一眼戳中目标人群或痛点。
- 正文 600–800 字，四段式：钩子 → 共鸣 → 干货 → 引导。
- 像闺蜜私聊，不像品牌文案。第一人称、短句、2–3 行一换行。
- 真实感 > 完美感：讲场景细节、适当说缺点，比"全都好"更可信。
- 全程零违禁词，功效不吹过头，结尾只引导一个动作。

## 1. 标题公式（≤20 字原则）

标题决定点击率，是笔记的第一生死线。从下面挑 1 个最贴选题的公式，套模板，控制在 20 字内（含 emoji 和符号）。

| 类型 | 模板 | 例子 |
|------|------|------|
| 数字结果型 | `[时间/数量]+[可量化结果]` | "用了3周，毛孔真的细了一圈"｜"30天瘦5斤的懒人吃法" |
| 人群锁定型 | `[具体人群]一定要看/别错过` | "油痘肌姐妹码住"｜"预算2000的新手妈妈看过来" |
| 痛点提问型 | `[痛点场景]怎么办？` | "一到换季就烂脸怎么救？"｜"每天加班没空护肤的人看这里" |
| 反常识型 | `[反直觉结论]，[补一句]` | "贵的精华不一定有用，这瓶平价的我回购3次" |
| 对比型 | `[A]VS[B]，[结论]` | "踩雷5支后，终于找到不卡粉的粉底" |
| 避坑型 | `别再[错误做法]了` | "别再交智商税了，这3样根本没必要买" |
| 自我暴露型 | `我[真实糗事/转变]` | "从满脸痘到素颜出门，我做对了这件事" |
| 清单型 | `[N]个[主题]，第N个绝了` | "5个被低估的国货，最后一个我天天用" |

写法红线：
- 数字、具体人群、具体场景越多越好；空泛的形容词（"超好用""绝绝子"堆砌）越少越好。
- 一个标题只承诺一件事，别既讲省钱又讲变美还讲省时间。
- 适当加 1 个 emoji 提升停留，但别超过 2 个。

输出标题时一次给 2–3 个候选，覆盖不同公式，让用户挑。

## 2. 正文结构：钩子 → 共鸣 → 干货 → 引导（总 600–800 字）

### ① 钩子（首屏，约 50–80 字）
小红书信息流只露出前两三行，这几行决定划走还是点开。目标：让目标人群"这说的就是我"。

- 用一个具体场景或一句扎心的话切入，别先自我介绍、别先讲背景。
- 可复用标题里的痛点，再补一刀细节。
- 例："姐妹们我真的栽了，换季第三天脸又开始爆皮，化妆全卡在法令纹里😭"

`[配图点位]` 首图通常是钩子的视觉化（对比图 / 痛点实拍 / 高颜值封面）。

### ② 共鸣（约 100–150 字）
先建立信任，再给方案。讲"我和你一样"的经历，让读者觉得你不是来卖货的。

- 描述你踩过的坑、走过的弯路、花过的冤枉钱。
- 适当暴露缺点和真实困扰，可信度反而更高。
- 例："试过十几款号称补水的，要么搓泥要么闷痘，钱包瘪了脸还是干。"

### ③ 干货（约 300–400 字，正文主体）
这是读者"码住"的理由。把方法/产品讲清楚、讲具体、能照着做。

- 用小标题或序号分点（1️⃣2️⃣3️⃣），每点一个要点 + 一句怎么用。
- 多讲使用场景、手法、时机、用量这类细节——细节=专业=真实。
- 该提缺点就提（"唯一缺点是味道有点冲，但能接受"），更显客观。
- 涉及产品时，描述"我怎么用、用完什么感受"，而不是复述卖点。

`[配图点位]` 每个干货分点配一张实拍/步骤图，正文里逐点标注。

### ④ 引导（结尾，约 50–80 字）
收个尾，只引导一个动作（评论 / 收藏 / 关注，三选一，别全要）。

- 用提问引导评论：互动率最高，平台也更愿意推。
- 例："你们换季都怎么救皮？评论区告诉我，我整理了张清单，需要的扣1我发你～"

## 3. 写作风格原则

- **口语化**：像跟闺蜜聊天，不像品牌官宣。多用"姐妹们""真的""我跟你说""绝了"这种私聊语气，少用"本产品""为您打造"这种书面词。
- **第一人称 + 短句**：每句尽量一行能读完，长句拆短。
- **勤换行**：2–3 行一空行，手机上才不显得密。
- **真实感优先**：讲具体场景和细节，适当承认缺点，比"样样完美"更让人信。
- **emoji 适量**：一段 1–2 个点缀情绪或分点（😭✨1️⃣👇），别每句都堆，廉价感。
- **结尾单一动作**：一篇只引导一个 CTA，多了等于没引导。

## 4. 广告法合规红线（必须遵守）

笔记一旦带营销性质就受《广告法》约束，违禁词会限流甚至下架。逐项自查：

### 4.1 禁用极限词（绝对不能出现）
- 最高级：最、最好、最佳、最强、最优、最便宜、最划算
- 排名类：第一、TOP1、排名第一、销量第一、冠军、领导品牌
- 绝对化：绝对、100%、全网唯一、独家、史无前例、永久、彻底、根治
- 权威背书：国家级、国家XX认证、央视推荐、专家推荐（无证据时）
- 升级版同义违规："yyds""天花板""无敌""封神"在营销语境同样有风险，能避则避。

### 4.2 功效宣称不超出可验证范围
- 只描述"使用体验"和"我的真实感受"，不下"治好/根治/必然有效"的结论。
- 化妆品禁用医疗用语：消炎、杀菌、抗炎、修复屏障（受限）、祛痘（药字号才可）、美白需有备案。
- 用"看起来更…""我觉得…""上脸感受是…"替代"一定能…""彻底解决…"。

### 4.3 医疗 / 金融 / 投资类主动降格
- 医疗健康：不承诺疗效，不诊断、不荐药，改为"我个人的调理体验，具体遵医嘱"。
- 金融投资：不承诺收益、不保本、不写"稳赚/翻倍/必涨"，加风险提示"投资有风险，仅个人记录非建议"。
- 凡是涉及人身/钱财的结论，一律降格为"个人经历分享"，并显式提示自行判断。

### 4.4 软广自然化
- 不写"广告""推广"字样裸露，但涉及合作必须按平台规则走蒲公英报备（这属发布环节，提醒用户即可）。
- 产品融进真实使用故事里，别像产品说明书堆参数。

### 违规 → 合规 改写对照

| ❌ 违规写法 | ✅ 合规写法 |
|------------|------------|
| 全网最好用的精华，没有之一 | 我回购了3次的精华，个人很爱 |
| 100%祛痘，一周根治 | 坚持用了一周，我的闭口看起来淡了一些 |
| 国家级认证，央视推荐 | 成分表干净，我自己用着安心 |
| 这只基金稳赚翻倍 | 这是我个人的持仓记录，投资有风险，非建议 |
| 绝对美白，立竿见影 | 上脸感觉提亮了点，肤色看起来均匀一些 |

## 5. 评论区引导（置顶评论）

发布后用作者身份置顶 1–2 条评论，承接正文 CTA、二次引导、补充信息。

- **承接型**（最常用）：把正文里"扣1发你"的钩子落地。
  例："统一回复～整理好的清单在这👉[补充内容]，姐妹们对症取用💕"
- **答疑型 / 引导互动**：抛一个具体问题，留下评论钩子。
  例："好多人问预算有限怎么选，你们现在卡在哪一步？评论区说说，我挨个回～"

置顶评论同样守第 4 节红线，别在评论区把正文降过格的话又吹回去。

## 6. 完整示例

**选题**：换季敏感肌的平价护肤分享（目标人群：20+ 学生党 / 职场新人，预算有限的油敏皮）

### 标题候选（挑 1 个发）
1. 油敏皮换季烂脸，靠这3样救回来了（痛点+结果型，19字）
2. 学生党别交智商税，平价护肤照样稳（人群+避坑型，16字）
3. 一到换季就爆皮怎么办？我的笨办法（痛点提问型，16字）

### 正文

姐妹们我真的栽了😭 换季第三天脸又开始爆皮，水乳一上脸就刺痛，化妆全卡在法令纹里，出门都不敢素颜。
