# 小红书发布手册

> **你的角色：发布运营。** 上游已交付成稿（文案终稿）和配图方案（封面文案），你这一棒负责把它们打包成一份「复制即发」的发布物料包——选好标签、定好发布时机、列好发布后黄金 1 小时的互动动作。你是小红书 team 的最后一棒：上游 `xhs-note-writing` 出成稿、`xhs-visual-method` 出封面文案，本 skill 收口成可发布物料。
>
> **边界先说清**（详见末尾「边界」）：第一版只产出物料、不代发；不承诺数据效果，只给可执行动作。

---

## 1. 标签金字塔（8-12 个，分四层）

标签不是越多越好，也不是随便堆热词。小红书的流量分发是「泛标签博曝光 + 垂直标签拿核心流量 + 长尾标签占搜索 + 系列标签沉淀人设」的组合拳。按下面四层配比，总数控制在 **8-12 个**。

| 层级 | 数量 | 作用 | 怎么选 |
|------|------|------|--------|
| **大流量泛标签** | 1-2 个 | 博曝光，进大池子 | 平台高频热门词，如 `#好物分享` `#生活记录` `#知识分享`。只放 1-2 个，多了稀释精准度 |
| **中部垂直标签** | 4-6 个 | **核心流量来源**，决定推给谁 | 紧扣笔记主题的赛道词，如保险方向用 `#保险知识` `#保险科普` `#家庭保障`。这是金字塔的腰，配比最重 |
| **小众长尾标签** | 3-4 个 | 搜索占位，吃精准搜索流量 | 用户真实会搜的具体短语，如 `#重疾险怎么买` `#30岁买什么保险`。竞争小、转化精准 |
| **账号系列专属标签** | 1 个 | 沉淀人设，做内容矩阵 | 自己造一个账号专属词，固定每篇都带，如 `#山大荣聊保险`。长期用能聚合你全部笔记，强化记忆点 |

**配比逻辑**：泛标签是「广撒网」，垂直标签是「找对人」，长尾是「等人搜」，系列是「记住我」。腰部（垂直）最厚，因为系统主要靠它判断把笔记推给哪个兴趣人群。

### 挑选方法

1. **先定垂直层**：列出笔记主题最直接的 4-6 个赛道词，这是骨架。
2. **再补长尾层**：把主题拆成用户的真实搜索句式（疑问句、场景句），找 3-4 个。
3. **配 1-2 个泛标签**：选与内容不冲突的大词，宁缺毋滥。
4. **固定 1 个系列标签**：账号统一，每篇都带。
5. **检索确认热度再用**：发布前在小红书搜索框逐个输入候选标签，看挂在该标签下的笔记量级和近期更新活跃度——有量、且近期有人发的才用；冷门到没人维护的标签等于浪费位。

### 避坑

- **避开平台限流/违禁词**：营销硬广词、绝对化用词（「最」「第一」「国家级」）、敏感行业词、诱导互动词（「点赞抽奖」类）可能触发限流，标签和正文都要避。
- **不堆同义重复标签**：`#保险` `#保险知识` `#保险科普` 三个挤在一起意义不大，垂直层选差异化的。
- **长尾不等于生造**：长尾标签也要是「真有人搜」的，检索确认有自然搜索量，别自己拍脑袋造一个零检索的词。
- **不超 12 个**：标签过多会被判定为标签堆砌，反而压制权重。

## 2. 发布时机基线

发布时机的目标：让笔记在**用户活跃高峰**进入流量池，争取启动阶段的互动密度。下面是通用时间窗，作为没有自有数据时的起步基线。

| 时段 | 窗口 | 适配人群 |
|------|------|----------|
| 工作日午间 | **12:00 - 14:00** | 午休刷手机的上班族 |
| 工作日晚间 | **19:00 - 23:00**（黄金段） | 下班后的主力活跃时段，流量最大 |
| 周末上午 | **9:00 - 11:00** | 周末睡醒后的悠闲浏览 |

**用法**：

- 默认推 **工作日晚间 19:00-23:00**，这是覆盖面最广的安全窗口。
- 内容若强场景（如早餐/通勤话题）就贴近对应时段发。
- **务必按账号实际数据修正**：这只是冷启动基线。账号跑一段后，打开后台「笔记数据」看自己粉丝的活跃时间分布，以自有数据为准——别人的高峰不一定是你的高峰。提醒用户：发布几篇后回看数据、校准自己的专属时间窗。

## 3. 黄金 1 小时互动清单

**为什么是这 1 小时？** 笔记发布后，系统会先推给一个小流量池测试反馈。这一小时内的互动密度（评论、点赞、收藏、停留）直接决定系统是否把你的笔记推进**下一个更大的流量池**。启动期数据差，后面再好也很难翻盘。所以发布后 1 小时不是「发完就走」，而是要主动经营。

发布后立即执行（按优先级）：

- [ ] **回复每一条评论**：来一条回一条，越快越好。评论区的互动量和往返对话是系统重点看的活跃信号，也能把读者留在页面更久。
- [ ] **置顶一条引导评论**：自己用小号或正文里抛一个能引发回复的钩子（如「你们家是先给大人还是先给孩子买？评论区说说」），置顶它，引导真实用户跟评。
- [ ] **转发到自己的私域**：第一时间转发到微信群、朋友圈、相关社群，引导熟人来点赞评论收藏，给启动期注入第一波真实互动。
- [ ] **引导收藏而非只点赞**：在回复里提示「觉得有用记得收藏」，收藏是小红书的强权重信号。
- [ ] **盯负面/疑问评论**：及时、专业地回应质疑，别让一条负评压住评论区氛围。
- [ ] **不删评、不刷量**：不要删除真实评论（哪怕中性），也不要机器刷赞——异常数据会被风控压权重。

这一小时的本质：用真实互动给系统一个「这篇值得推」的信号。

## 4. 发布物料包模板（复制即发）

把上游成稿 + 本 skill 的标签/时机/互动，收口成下面这份模板，**用户复制即可直接发布**。

```
========== 小红书发布物料包 ==========

【最终标题】
<20 字以内，带 1-2 个 emoji，含一个钩子/数字/痛点>

【正文终稿】
<开头 2 行先抛钩子>
<正文分段，每段 2-3 行，多用 emoji 分隔和换行，避免大段文字>
<结尾一句引导互动的钩子，如"评论区聊聊你的情况">

【标签组合】（8-12 个，已检索确认热度）
泛流量：#xxx #xxx
垂直层：#xxx #xxx #xxx #xxx
长尾层：#xxx #xxx #xxx
系列标签：#xxx

【封面/配图】
封面主文案：<来自 xhs-visual-method>
配图建议：<张数 / 顺序 / 关键画面>

【发布建议】
推荐发布时间：<具体时间窗，附"建议按你的后台粉丝活跃数据校准">
黄金 1 小时动作：回复全部评论 / 置顶引导评论 / 转发私域群 / 引导收藏

====================================
```

**填写要点**：

- 标题和正文用上游成稿，不要在这一棒重写文案——你的职责是打包，不是改稿。
- 正文 emoji 换行要保留成稿里的排版，别压成一坨。
- 标签必须是已检索确认过热度的，不放占位符。
- 发布时间给具体窗口 + 一句「按自有数据校准」的提醒。

## 5. 边界

- **第一版只产出物料、不代发。** 小红书没有开放的第三方发布接口，任何「代发」都要靠模拟登录/自动化操作，有封号和账号风险。本 skill 只交付「复制即发」的物料包，由用户本人在客户端手动发布。
- **不承诺数据效果，只给可执行动作。** 流量是平台算法 + 内容质量 + 时机的综合结果，没人能保证爆。本 skill 给的是经过验证的**可执行动作清单**（怎么配标签、何时发、发后做什么），不是「保证涨粉/上热门」的承诺。
- **标签热度、限流词、活跃时段会随平台规则变化**，模板里的具体数值是基线，要求用户用最新检索和自有后台数据修正。
