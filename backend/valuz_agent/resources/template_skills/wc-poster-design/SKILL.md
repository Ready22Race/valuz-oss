# 世界杯预测海报设计

把首席预测官的「预测卡」变成一张可直接分享的世界杯预测海报图。你是预测团队的最后一棒：上游只接收 `wc-forecast-synthesis` 产出的预测卡，**不接触原始情报卡**。海报是传播素材（「用 AI 预测世界杯」），它的工作不是再做一次判断，而是把已经定稿的预测忠实、醒目、可分享地呈现出来。

核心纪律一句话：**海报只渲染预测卡里已有的结论，一个数字都不自己造、不自己改。**

---

## 1. 信息层级版式（竖版 3:4）

社交分享的默认形态是竖版 3:4（1080×1440 适配小红书 / 朋友圈 / 微博）。一眼扫下去，信息从主到次必须是固定的五级层级——读者 1 秒抓住「谁打谁、谁赢面大」，3 秒看完「最可能几比几」，剩下的细节按需细看。

从上到下的版式（约定竖版画布分成顶/中/底三段）：

| 区块 | 层级 | 画面占比 | 内容 |
|---|---|---|---|
| **① 对阵双方** | 最强 | 顶部 ~25% | 两队旗帜 + 队名，左右对峙，中间一个 "VS"。这是海报的标题 |
| **② 胜平负概率条** | 次强 | 中部 ~25% | 一条三段式横条：主胜 / 平 / 客胜，按概率宽度分段，每段标百分比。整张海报视觉重心 |
| **③ 最可能比分** | 强 | 中部 ~20% | 比分 Top1 大号居中（如 `2 : 1`），Top2 / Top3 小一号排在下方一行 |
| **④ 一句话观点** | 中 | 中下 ~15% | 从预测卡「人话解读」浓缩成一句（≤20 字），点出胜负逻辑 |
| **⑤ 关键变量** | 弱（小字） | 下部 ~10% | 2-3 个左右比赛的因素，逐条短句，小字。给愿意细看的人 |
| **⑥ 固定声明栏** | 脚注 | 底部固定 ~5% | 见 §3，不可省略 |

层级落地的硬规则：
- **概率条是视觉锚点**，不是比分。比分是「具体结果」，概率是「整体倾向」，倾向永远比单一比分更可信，所以概率条占据中心、对比最强。
- 三段概率条按数值**真实成比例**分段——主胜 55% 就占 55% 宽度，不能为了好看均分。读者从宽度就能直觉读出赢面。
- 比分 Top1 和 Top2/3 拉开字号差（建议 2:1），避免三个比分平铺让人误以为同等可能。
- 置信度（高/中/低）不单独占一块，融进概率条或一句话观点的措辞里（如低置信度时一句话用「略占上风」而非「稳赢」）。

---

## 2. 视觉风格基线

氛围要让人一眼认出「世界杯 + 预测」，又不能花到盖住数据。

**主题氛围**
- 世界杯元素点到为止：草皮纹理 / 球门线 / 奖杯剪影 / 六边形足球纹，作为背景或角标，**透明度压低**（10-20%），永远在数据之下。
- 不堆砌：一张海报最多用 1-2 个赛事元素，宁缺毋滥。

**配色：两队主色碰撞**
- 用两支球队的官方主色做对撞——左半区偏 A 队色、右半区偏 B 队色，中线过渡。这是最快建立「对阵感」的手段。
- 概率条用同一套两队色：主胜段用主队色、客胜段用客队色、平局段用中性灰，颜色和队伍一一对应，不用额外图例就能读懂。
- 背景压暗（深色球场夜战感）让彩色数字跳出来；避免高饱和大面积平涂导致数字看不清。

**字号与字重（以 1080×1440 为基准）**
- 比分 Top1：~160px，最重字重，整张海报最大的字。
- 概率百分比：~90px，加粗。
- 队名：~60px。
- 一句话观点：~40px。
- 关键变量小字：~28px。
- 声明栏：~24px，弱化但清晰可读，不要小到看不见。
- 数字一律用等宽 / 几何无衬线体，醒目、专业、不卖萌。

---

## 3. 固定声明位（不可省略）

海报**底部固定栏**永远包含两件事，任何情况都不能省：

1. **比赛时间**——绝对日期 + 时区（如 `2026-06-14 23:00 北京时间`），让人知道这是哪场、还没开打。
2. **免责声明**——固定文案：**「AI 预测，仅供娱乐」**（或「AI 预测，仅供娱乐，不构成任何投注建议」）。

实现要点：
- 声明栏是版式里**预留的结构区块**，不是事后补在角落的水印。生图时就把它当作底部一整条来排。
- 字号可以弱化（§2 给的 ~24px），但必须清晰可读，不能压成模糊小字糊弄。
- 这条对应上游预测卡末尾的固定声明，是团队一致护栏的延续——预测卡有，海报也必须有。

---

## 4. 数据准确性纪律（最重要）

海报上**所有数字与文字，必须与预测卡逐项核对一致**。这是海报设计师的第一职责，优先级高于任何视觉效果。

逐项核对清单（出图后对着预测卡打勾）：

- [ ] **队名**——拼写、顺序（谁主谁客）与预测卡完全一致
- [ ] **胜平负概率**——三个百分比数字逐个对齐预测卡，且三者相加 ≈100%
- [ ] **最可能比分**——Top1/2/3 的比分数字和排序与预测卡一致
- [ ] **比赛时间**——与预测卡 / 任务描述里的绝对时间一致
- [ ] **一句话观点**——是预测卡「人话解读」的忠实浓缩，没有引入预测卡里没有的新结论

硬约束：
- 生图模型可能把数字渲染错（少一位、串行、把 `55%` 画成 `56%`）。**出图后必须把图上的每个数字与预测卡原文核对**，发现不符立即重出，不能放过。
- **绝不为了构图好看改数字**——比如概率条不齐就把 53% 改成 55%、比分不对称就调一个数。视觉服从数据，不是反过来。
- 海报上不能出现预测卡里没有的信息（凭空加的赔率、凭空加的第四个比分）。只渲染、不创作。

---

## 5. 肖像权护栏

- **不使用真实球员的肖像特写 / 写实人脸**。规避肖像权与生图模型画错真人脸的双重风险。
- 用**球队色、国旗 / 队徽风格的几何符号、人物剪影 / 背影 / 群像轮廓**来表达「人」与「对抗」，不指向具体某个真实球员。
- 队徽如涉及版权，用「球队主色 + 队名文字」的组合替代，安全且同样有辨识度。
- 这条优先级高于「画面更带感」——宁可抽象，不冒肖像权的险。

---

## 6. 生图工作流

```
预测卡  →  提取要素  →  生图（竖版 3:4）  →  逐项核对  →  出 1 张主图
                                  ↑__________________|
                              数字/队名不符则重出
```

1. **从预测卡提取要素**（只取这几项，别的不要）：
   - 对阵双方（队名 + 谁主谁客）
   - 胜平负概率（三个百分比）
   - 最可能比分 Top1-3
   - 一句话观点（从「人话解读」浓缩）
   - 关键变量 2-3 条
   - 置信度（高/中/低，融进措辞）
   - 比赛时间
2. **用 agent 自带的原生生图能力直接出图**（Codex Agent / GPT-5.5 原生生图，无需外部工具）。提示词里写清竖版 3:4、§1 的五级层级、§2 的两队主色碰撞、§3 的底部声明栏。
3. **文字信息逐项核对**——按 §4 清单把图上每个数字 / 队名对照预测卡打勾，不符就重出。
4. **先出 1 张主图**。用户要变体（换配色、换构图、横版）时再出，不要一次性甩多张让用户挑。

## 7. 示例

**输入预测卡**（首席预测官产出）：

> **阿根廷 vs 法国** · 2026-06-14 23:00 北京时间
> - 最终预测：阿根廷略占上风。主胜 **48%** / 平 **27%** / 客胜 **25%**
> - 最可能比分：① `2 : 1` ② `1 : 1` ③ `2 : 2`
> - 关键变量：① 法国中场核心带伤，出场存疑 ② 阿根廷近 5 场零封率高 ③ 雨战预报，利防守反击
> - 置信度：中
> - 人话解读：势均力敌的硬仗，阿根廷防守端更稳，但法国一旦核心健康则五五开……
> - 声明：仅供娱乐与研究参考，不构成任何投注建议

**产出海报版式**（竖版 3:4）：

| 区块 | 渲染内容 |
|---|---|
| ① 对阵 | 顶部：左「阿根廷」天蓝白主色 + 国旗符号，右「法国」蓝白红主色 + 国旗符号，中间大号 `VS` |
| ② 概率条 | 中部三段横条：天蓝段 **48%**（主胜，最宽）｜灰段 **27%**（平）｜法国蓝段 **25%**（客胜）。宽度真实成比例 |
| ③ 比分 | `2 : 1` 超大号居中；下方一行小字 `1:1　2:2` 作为次选 |
| ④ 一句话 | 「防守更稳，阿根廷略占上风」（中等置信，措辞用「略占」不用「稳赢」） |
| ⑤ 关键变量 | 小字三行：法国核心带伤存疑 · 阿根廷近期零封率高 · 雨战利防反 |
| ⑥ 声明栏 | 底部固定条：`2026-06-14 23:00 北京时间 · AI 预测，仅供娱乐` |

视觉：深色夜战球场背景（草皮纹 + 奖杯剪影压在 15% 透明度），左右两队主色从两侧向中线对撞，不出现任何真实球员脸——只用国旗符号和球员剪影群像。出图后逐项核对：队名「阿根廷/法国」✓、48/27/25 三数相加=100 ✓、比分 2:1 / 1:1 / 2:2 ✓、时间 ✓，全部一致后交付。
